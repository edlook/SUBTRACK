FAQ

Questions and Answers

Short, honest answers before you install

Is SubTrack Pro free?

Yes. SubTrack Pro is free to install and use. There are no paid tiers and no ads.

Do I need an account?

No. There is no sign-up, no login and no cloud sync. You install the extension and start adding subscriptions.

Where is my data stored?

Locally in your browser, using Chrome's extension storage (chrome.storage). Your subscription list is not sent to us or to any server. If you uninstall the extension, Chrome deletes this data, so export a CSV first if you want a copy.

Which permissions does it ask for, and why?
  • Storage: saves your subscriptions and settings in your browser.
  • Alarms and notifications: show reminders before a payment or trial ends.
  • Access to supported subscription sites (for example Netflix or Spotify): recognises the service when you visit it. The extension does not run on other websites.
  • Email sites (Gmail, Outlook, Yahoo Mail): requested only if you turn on inbox scanning.
Does it read my email?

Only if you turn it on. Inbox scanning is off by default. If you switch it on in the settings, Chrome asks you to allow access to your webmail, and the extension then looks for subscription receipts on those pages. This happens in your browser. You can switch it off again at any time.

Which browsers does it work in?

SubTrack Pro is built for Google Chrome on desktop (Windows, macOS, Linux and ChromeOS). It is not available for phones, Firefox or Safari. Other Chromium browsers that install extensions from the Chrome Web Store may work, but they are not officially supported.
